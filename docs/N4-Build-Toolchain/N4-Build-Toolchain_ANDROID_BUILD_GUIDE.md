# Android Build Guide — AAB & APK

Complete guide for building and releasing KitchnTabs on Android using Capacitor + Gradle.

---

## Quick Start

### Build AAB (Recommended for Google Play Store)
```bash
pnpm release:android:kitchntabs-app:production
```

### Build APK (Direct Installation / Testing)
```bash
pnpm release-apk:android:kitchntabs-app:production
```

---

## Build Types Explained

### **AAB (Android App Bundle)**

**What it is:**
- Single file format for Google Play Store distribution
- Google Play automatically generates device-specific APKs for each user
- Smaller download size for end users (only code/resources for their device)
- Required for Google Play Store submission

**File size:** ~60-80 MB (bundle)
**User download:** ~30-40 MB (device-specific APK)
**Best for:** Production / Google Play Store release

**Command:**
```bash
pnpm release:android:kitchntabs-app:production
```

**Output:**
```
android/app/build/outputs/bundle/release/
└── app-release.aab (signed)
```

**Installation:**
- Upload to [Google Play Console](https://play.google.com/console)
- Google Play tests & distributes to users

---

### **APK (Android Package)**

**What it is:**
- Direct installable package for Android devices
- Contains all code/resources for all device configurations
- Larger file size (includes unused resources for other devices)
- Can be installed directly via USB or shared file

**File size:** ~120-150 MB
**Installation:** Direct on device
**Best for:** Testing, internal QA, direct distribution

**Commands:**
```bash
# Standard APK build
pnpm release-apk:android:kitchntabs-app:production

# Development APK (unoptimized, faster build)
pnpm release-apk:android:kitchntabs-app:production
```

**Output:**
```
android/app/build/outputs/apk/release/
└── app-release.apk (signed)
```

**Installation:**
```bash
# Via USB (device connected)
adb install -r android/app/build/outputs/apk/release/app-release.apk

# Or share the .apk file for direct installation
```

## Prerequisites

### Android Development Tools

```bash
# Check if installed
which adb          # Android Debug Bridge
which gradle       # Build system
which keytool      # Signing tool

# Install via Homebrew (if missing)
brew install android-sdk android-ndk gradle
```

### Capacitor Setup
```bash
# Verify Capacitor Android is installed
ls android/
# Should show: app/, gradle/, gradlew, settings.gradle, etc.

# If not, sync:
pnpm exec capacitor sync android
```

### Signing Configuration

Android requires all APKs to be **signed** before release. Configuration is in:
```
android/app/build.gradle
```

Look for `signingConfigs` section. Two options:

#### Option 1: Debug Keystore (For Testing)
Auto-generated by Gradle, located at:
```
~/.android/debug.keystore
```
No action needed — Gradle uses this automatically for debug/APK builds.

#### Option 2: Release Keystore (For Play Store)
You must create or provide this for production AAB releases.

**Create a new release keystore:**
```bash
keytool -genkey -v -keystore kitchntabs.keystore \
  -keyalg RSA -keysize 2048 -validity 36500 \
  -alias kitchntabs-release
```

Then configure in `android/app/build.gradle`:
```gradle
signingConfigs {
  release {
    storeFile file('path/to/kitchntabs.keystore')
    storePassword 'your_store_password'
    keyAlias 'kitchntabs-release'
    keyPassword 'your_key_password'
  }
}
```

**Secure approach** (environment variables):
```bash
# Set in your shell
export KEYSTORE_FILE="/path/to/kitchntabs.keystore"
export KEYSTORE_PASSWORD="your_store_password"
export KEY_ALIAS="kitchntabs-release"
export KEY_PASSWORD="your_key_password"
```

## Build Environment

### Development vs Production

```bash
# Both use these environment variables (set by pnpm scripts):
MODE=production
CUSTOM_MODE=kitchntabs.production
TARGET_TYPE=mobile
PLATFORM=android
APP_PATH=apps/kitchntabs-app
```

These trigger:
1. Production React build (minification + console stripping)
2. Capacitor config for Android
3. Gradle release build
4. APK/AAB signing

### Node/Java Memory Requirements

```bash
# For large builds, increase memory:
export NODE_OPTIONS=--max-old-space-size=4048
export GRADLE_OPTS="-Xmx4096m -Xms2048m"

# Then run build
pnpm release:android:kitchntabs-app:production
```

## Step-by-Step Build Process

### For AAB (Play Store)

```bash
# 1. Set production config
pnpm config:android:kitchntabs-app:production
# Generates build_config.json with CUSTOM_MODE=kitchntabs.production

# 2. Copy Android resources (icons, splash screens)
pnpm resources:android
# Generates android/app/src/main/res/ from assets/

# 3. Build React app
pnpm config:android:kitchntabs-app:production && \
NODE_OPTIONS=--max-old-space-size=4048 \
turbo build --filter=kitchntabs-app --no-cache
# Outputs: apps/kitchntabs-app/dist/

# 4. Sync Capacitor (native iOS/Android bridge)
pnpm exec capacitor sync android
# Updates android/app/src/main/java (Capacitor plugins)

# 5. Build Gradle (AAB)
cd android && ./gradlew bundleRelease
# Outputs: app/build/outputs/bundle/release/app-release.aab

# OR: Run the combined pnpm script
pnpm release:android:kitchntabs-app:production
```

### For APK (Direct Installation)

```bash
# Same as AAB up to step 4, then:

# 5. Build Gradle (APK)
cd android && ./gradlew assembleRelease
# Outputs: app/build/outputs/apk/release/app-release.apk

# OR: Run the combined pnpm script
pnpm release-apk:android:kitchntabs-app:production
```

## Build Scripts in package.json

```json
"release:android:kitchntabs-app:production": "pnpm resources:android && pnpm config:android:kitchntabs-app:production && turbo build --filter=kitchntabs-app --no-cache && cap sync android && cd ./android && ./gradlew bundleRelease",

"release-apk:android:kitchntabs-app:production": "pnpm resources:android && pnpm config:android:kitchntabs-app:production && turbo build --filter=kitchntabs-app --no-cache && cap sync android && cd ./android && ./gradlew assembleRelease"
```

Both scripts:
1. `pnpm resources:android` — Generate icons/splash from assets
2. `pnpm config:android:...` — Set build configuration
3. `turbo build --filter=kitchntabs-app --no-cache` — Build React app
4. `cap sync android` — Sync Capacitor bridge
5. `./gradlew bundleRelease` or `./gradlew assembleRelease` — Package


## Google Play Store Release

### Prepare for Submission

1. **Get signing certificate fingerprint:**
```bash
keytool -list -v -keystore ~/.android/debug.keystore
# For release builds, use your release keystore instead
```

2. **Update app metadata in `android/app/build.gradle`:**
```gradle
android {
  defaultConfig {
    applicationId "com.kitchntabs.app"
    minSdkVersion 24
    targetSdkVersion 34
    versionCode 1
    versionName "1.3.37"
  }
}
```

3. **Version management:**
```bash
# Auto-increment version code before each release
pnpm exec increment-android-version.js
# Updates android/app/build.gradle with new versionCode
```

### Upload to Play Console

1. Go to [Google Play Console](https://play.google.com/console/u/0/developers)
2. Select KitchnTabs project
3. Navigate to **Release** → **Production** → **Create release**
4. Upload `app-release.aab` from `android/app/build/outputs/bundle/release/`
5. Add release notes
6. Review and submit

Google Play will:
- Scan for security issues
- Generate device-specific APKs
- Distribute to users
- Track analytics

## Local Testing (APK)

### Install via ADB

```bash
# Connect device via USB (with USB debugging enabled)
adb devices
# Should list your device

# Install APK
adb install -r android/app/build/outputs/apk/release/app-release.apk

# Launch app
adb shell am start -n com.kitchntabs.app/.MainActivity

# View logs
adb logcat | grep kitchntabs
```

### Install via File Sharing

```bash
# Share the APK file
cp android/app/build/outputs/apk/release/app-release.apk ~/Desktop/

# Send to device via email/Slack/Drive
# On device: Open file manager → Download → Open app-release.apk → Install
```

## Troubleshooting

### Build Fails: "Gradle Sync Failed"

```bash
# Clean and retry
cd android && ./gradlew clean && ./gradlew bundleRelease

# Or from project root
pnpm run resources:android
pnpm config:android:kitchntabs-app:production
turbo build --filter=kitchntabs-app --no-cache
pnpm exec capacitor sync android
cd android && ./gradlew bundleRelease
```

### Build Fails: "Keystore not found"

Ensure signing config paths are correct:
```bash
# Check if keystore exists
ls -la ~/.android/debug.keystore

# For release, verify path in android/app/build.gradle
grep -A 5 "signingConfigs" android/app/build.gradle
```

### Build Fails: "Out of Memory"

```bash
# Increase Java/Node heap
export NODE_OPTIONS=--max-old-space-size=8192
export GRADLE_OPTS="-Xmx8192m -Xms4096m"

# Retry
pnpm release:android:kitchntabs-app:production
```

### APK Installation Fails: "App not installed"

```bash
# Check device compatibility
adb shell getprop ro.build.version.release    # Android version
adb shell getprop ro.product.cpu.abi          # CPU architecture

# Verify APK is compatible
aapt dump badging android/app/build/outputs/apk/release/app-release.apk | grep "uses-permission"
```

### Console Logs Not Visible in Production

This is **expected**. Production builds have:
- ✅ Console statements removed (esbuild drop)
- ✅ Minified code
- ✅ Only error logging

To see logs in production:
```bash
# Use electron-log (main process) or send to backend
# Or install dev/staging APK instead (keeps console)
pnpm dev:android:kitchntabs-app:development
```

## Version Management

### Auto-Increment Version Code

```bash
# Create/run script before each Play Store release
node scripts/increment-android-version.js

# Updates android/app/build.gradle:
# versionCode: 1 → 2 → 3, etc.
```

### Version vs Version Code

| Field | Purpose | Example |
|-------|---------|---------|
| `versionName` | User-visible version | "1.3.37" |
| `versionCode` | Internal build counter | "137" or "1" |

Google Play requires `versionCode` to increase with each upload.

## Development vs Production

### Development Build (Faster, Unoptimized)

```bash
pnpm dev:android:kitchntabs-app:development
```

**Features:**
- ✅ No minification (fast builds)
- ✅ Console logs visible
- ✅ Source maps for debugging
- ✅ Smaller app size

### Production Build (Optimized, Signed)

```bash
pnpm release:android:kitchntabs-app:production
```

**Features:**
- ✅ Minified code
- ✅ Console logs removed
- ✅ Proper signing (release keystore)
- ✅ Optimized resources
- ✅ Slower build, but optimal runtime

## APK vs AAB Decision Tree

```
┌─ Need to submit to Google Play Store? ─┐
│ YES → Use AAB                          │
│       pnpm release:android:...         │
│ NO  → Need to test/install directly?  │
└─────────────────────────────────────────┘
        │
        ├─ YES → Use APK
        │        pnpm release-apk:android:...
        │        adb install app-release.apk
        │
        └─ NO  → Use AAB for future Play Store
                 pnpm release:android:...
```

## Gradle Configuration Reference

Key files:
- `android/build.gradle` — Project-level settings
- `android/app/build.gradle` — App-level settings (versionCode, signing, etc.)
- `android/gradle.properties` — Gradle JVM options
- `android/gradle/wrapper/gradle-wrapper.properties` — Gradle version

Edit these if you need to:
- Change app ID (`applicationId`)
- Update min/target SDK versions
- Configure signing keystore
- Add Gradle plugins
